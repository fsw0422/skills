# Profile template

Two files in the profile directory (`$WRITE_AS_ME_DIR` or `~/.config/write-as-me/`). Keep them private.

## style-guide.md

```markdown
# <Name>'s voice

Built on <date> from about <N> of their messages (<date range>) and <M> full threads. Pasted AI output was excluded.

## Identity

- <Name>, Slack user ID <USER_ID> (for `from:<@USER_ID>` searches).
- <Role / team>. <Where requests usually come in>.

## Personal hard rules

- <Rules that always apply, e.g. "No profanity", "One sentence per line", "Default register is slightly formal">

## Core voice (every register)

- <Length and structure>
- <Hedging and directness>
- <Formatting habits: arrows, CAPS, quoting, links>
- <"I" vs "we">

## Registers

| | Internal casual | Slightly formal (default) | Formal (external) |
|---|---|---|---|
| Opener | | | |
| Sentence starts | | | |
| Final period | | | |
| Abbreviations | | | |
| Emoji | | | |
| Typos, missing articles | | | |
| Thanks | | | |
| Sentence length | | | |

## Slightly-formal baseline

Keep:
- <habits that stay>

Tidy:
- <habits that get fixed, e.g. recurring typos and their fixes>

## Investigation / incident write-ups

- <Length, structure, bullets vs prose, how confidence and next steps are stated>

## Common phrases

- <By function: asking, hedging, proposing, acknowledging, thanks, closing>

## Avoid

- <Patterns this person never uses, plus AI tells>
```

## examples.md

```markdown
# Examples

Paraphrased, with names and details replaced by placeholders.

## <Situation> (<register>)
<example message, with exact line breaks, capitalization, punctuation and emoji>
```

Cover at least: asking for a review, answering a support question, closing a ticket, an incident update, an investigation write-up, a proposal or options, polite disagreement, a cross-team request, and one formal / external message. Include one casual vs slightly-formal pair of the same message.
